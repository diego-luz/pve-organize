Features

Small add-on, big difference in a busy cluster

Everything happens in the web UI. Nothing new is stored on your guests.

Two levels

A top level (big header) and, if you want, a subcategory (subheader) for each guest.

Built on Proxmox tags

A guest tagged Production;Network shows up under PRODUCTION › Network. No new data on the servers.

Right-click → Move to group

Change a guest's group in two clicks, straight from the tree.

Tree groups screen

Create groups, pick colors or let them be automatic, drag to reorder, 6 styles, counter, indent and an ON/OFF switch — with live preview.

Shared by the whole cluster

Settings live in the Datacenter Notes and Tag Style, so every admin and browser sees the same tree.

Survives Proxmox updates

An apt hook puts it back after upgrades. Follows the Proxmox language: English, Portuguese and Spanish.

Screens

Make it look the way you like

Six header styles, dark and light themes, and a settings screen right inside the Proxmox UI.

Install

One command. Then F5.

The installer downloads the latest release and checks every file against its SHA256SUMS before installing.

01

Open a shell on the node

In the web UI: select the node → >_ Shell. Or over SSH, as root. Not on your own computer.

bash
$ ssh root@<node-ip>
02

Run the installer

It installs the latest published version and stops if any checksum does not match.

bash
# bash -c "$(curl -fsSL \
  https://github.com/diego-luz/pve-organize/releases/latest/download/install.sh)"
03

Reload the web UI

Back in the browser, press F5. Right-click a guest → Move to group, or open Tree groups… to set things up.

browser
F5 → https://<node-ip>:8006

Tested on Proxmox VE 9.2 and 8.4. 8.0–8.3 are allowed with a warning; versions before 8 are refused. In a cluster, install on each node whose web UI you use.

Simple to control

Turn it off and the original Proxmox tree is back; your groups stay saved. Uninstall removes everything that was installed.

bash
# pve-organize status   # version, on/off, apt hook…
# pve-organize off      # remove from the UI, keep config
# pve-organize on       # load it again
# pve-organize uninstall

FAQ

Frequently asked questions

Is it free?
Yes. pve-organize is open source under the MIT license.
Does it change my VMs or containers?
Only their tags, and only when you move a guest to a group. Groups, order and style are saved in a hidden block at the end of Datacenter → Notes; colors go to Datacenter → Options → Tag Style. The rest of your notes is untouched.
What happens when I update Proxmox?
An apt hook re-applies the add-on after Proxmox updates. If something ever looks wrong, pve-organize off and F5 bring back the original tree.
Do I need to install it on every node?
On each node whose web UI you open. The configuration itself is stored at the Datacenter level, so all nodes and browsers share the same groups.
Can I use it together with pools?
Yes. pve-organize is purely visual. If you need permissions per group, keep using pools for that.
How do I update or uninstall?
To update, run the install command again — it always fetches the latest release. To remove it, run pve-organize uninstall and press F5. What changed in each version is in the CHANGELOG.
Is it affiliated with Proxmox?
No. It is a community project, not affiliated with Proxmox Server Solutions GmbH.
